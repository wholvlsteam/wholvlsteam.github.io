历史坐标

一个人的历史阅读地图 · 中国史与世界史

这里是我整理历史阅读的地方。历史对我来说不是一堆要背的年代，而是一张需要慢慢填满的坐标网——先记住大致轮廓，再挑感兴趣的节点往里钻。这个站点用来记录我填到了哪一步。

四个板块

  • CHECKLIST

    历史打卡清单

    中国史与世界史的时间轴清单，按「待了解 / 简单了解 / 深度了解」三档标注掌握程度，已深入的条目标注了书单与资源。
  • MAPS

    历史地图收藏

    收集的历史地图与古地图，每张都标注年代、来源与授权方式。
  • LIBRARY

    资源书架

    读过的历史书与仍在读的，附一句话短评和合法的获取渠道。
  • TRAVEL

    旅行足迹

    到过的历史现场，地图上标出位置，每个地方留一段记录。

关于本站

本站用 Hexo 生成，托管在 GitHub Pages 上。页面里的图片分两类：一是我自己绘制或拍摄的，二是从公有领域来源取得的，后者会在图注里标明来源与授权方式。书目一律只给出合法获取渠道，不提供电子书文件下载。

文章列表：随手的读史笔记放在文章归档里，那里是完整的博客文章列表。
